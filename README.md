# Rennes Data Challenge

Projet réalisé dans le cadre du Data Challenge.

## Objectif
Analyser des données économiques / financières et proposer une approche data-driven.

## Structure du projet
- data/ : données
- notebooks/ : notebooks d'analyse
- requirements.txt : dépendances Python

## Installation
```bash
uv venv
